# Personal Website — Capstone Project 2

What I did
- Added a unified `style.css` (fonts, colors).
- Built sticky navigation with active-link + hover effects.
- Implemented three layouts: Flexbox (Home), Float/Position (Schedule), Grid (Gallery).
- Styled tables, lists, forms; added dotted `<hr>` and Google Font.
- Made a responsive Gallery (3 per row desktop, 1 per row mobile) with media queries.
- Enhanced Contact page with Bootstrap (form controls, utilities).

What I learned
- When to use Float/Position vs Flexbox vs Grid.
- Creating a single design system via variables and reusable classes.

Purpose
- A simple personal/portfolio site for practice and deployment on GitHub Pages.
